# Concert Mod (Minecraft Forge 1.12.2)

Мод для концертов: сцена, ферма, колонки, LED-экран, прожекторы, цветные лампы и стробоскопы.

## Важно: сборка

Код написан под Forge 1.12.2 (14.23.5.2860, маппинги stable_39), но **в этой среде я не мог его скомпилировать**
(нет доступа к Forge/Gradle). Синтаксис проверен, а вот сборка и запуск в игре — не проверены.
Если при сборке будут ошибки, пришли лог — я исправлю.

### Как собрать
1. Установи **JDK 8**.
2. Скачай официальный **Forge MDK 1.12.2** (files.minecraftforge.net, версия 14.23.5.2860).
3. Распакуй MDK, удали из него папку `src`, скопируй вместо неё папку `src` из этого проекта.
4. В `build.gradle` MDK поставь `version = "1.0.0"`, `group = "com.concertmod"`, `archivesBaseName = "concertmod"`
   (или возьми `build.gradle` из этого проекта).
5. В папке MDK выполни: `gradlew setupDecompWorkspace`, затем `gradlew build`.
6. Готовый мод: `build/libs/concertmod-1.0.0.jar` → положи в папку `mods` Forge 1.12.2.
   Для проверки без сборки jar: `gradlew runClient`.

## Блоки (креативная вкладка «Концерт»)

| Блок | Что делает |
|---|---|
| Колонка | Декоративная, передней стороной смотрит на игрока при установке |
| Блок сцены | Тёмный пол сцены |
| Ферма (трасса) | Прозрачная металлическая решётка для подвеса света |
| LED-экран | Анимированный разноцветный экран, светится; все блоки играют синхронно |
| Прожектор | Вращающаяся голова + светящийся луч (упирается в блоки) |
| Цветная лампа | Светится выбранным цветом, свет 15 |
| Стробоскоп | Лампа, которая мигает |
| Конфетти-пушка | Выстрел разноцветным конфетти (со звуком) или непрерывная струя |
| Дым-машина | Три типа дыма: густой (клубится и поднимается), стелющийся (по полу), дымка (тонкая, висит долго). Цвет окрашивает дым |
| Огнемёт (пламя) | Короткие залпы огня метров на 5–6 (как настоящие сценические огнемёты); только визуальный эффект — не жжёт игроков/мобов и не поджигает блоки |

### Машины эффектов (конфетти, дым, огонь)
У каждой два режима:
- **выстрелы** — один выстрел при включении и дальше новый выстрел каждые `20/speed` тиков, пока машина включена
  (по умолчанию так работают конфетти и огонь);
- **непрерывно** — эффект идёт всё время, пока машина включена (по умолчанию у дыма).

Ствол по умолчанию смотрит вверх, наводится палкой/огненным стержнем или командой `/concert aim`.
Порох в руке (правый клик по машине) переключает режим выстрелы ↔ непрерывно.
Цвет влияет на конфетти (белый = разноцветное) и дым; у огня цвета нет.

## Управление

**Редстоун:** прожектор, лампа и стробоскоп включаются сигналом редстоуна.

**Правый клик пустой рукой — открывает меню управления** (слева — палитра, RGB-ползунки и «радуга», справа — настройки именно этого устройства: движение луча и наведение у прожектора; режим, кнопка «ВЫСТРЕЛ!», тип дыма и наведение у машин). Изменения видны сразу, пока двигаешь ползунки.

**Крепление к потолку:** поставь прожектор или машину на **нижнюю грань** блока (кликни по потолку снизу) — устройство повиснет вверх ногами. Конфетти-пушка и огнемёт при этом смотрят вниз, а конфетти сыплется широким «дождём».

**Быстрые действия:**
- `Shift` + пустая рука — включить/выключить без редстоуна;
- палка по прожектору — повернуть на 15° по горизонтали;
- огненный стержень по прожектору — наклон на 15°;
- светопыль по прожектору — сменить режим движения (неподвижный → качание → круг → вращение).

**Команда `/concert`** (нужны права оператора, работает и в командных блоках). Действует на все устройства
вокруг отправителя, радиус по умолчанию 64 блока (максимум 512):

```
/concert on|off [радиус]
/concert fire [радиус]                                 (один выстрел конфетти/дыма/огня)
/concert burst <on|off> [радиус]                       (машины: on = выстрелы, off = непрерывно)
/concert color <red|blue|...|#RRGGBB> [радиус]
/concert rainbow <on|off> [радиус]
/concert strobe <on|off> [радиус]
/concert mode <static|sweep|circle|spin> [радиус]     (только прожекторы)
/concert speed <0.1-10> [радиус]
/concert aim <yaw> <pitch> [радиус]                    (прожекторы и машины; pitch>0 — вниз, -90 — вверх)
```

Цвета: white, red, orange, yellow, lime, green, cyan, blue, purple, magenta, pink или любой `#RRGGBB`.

Примеры: `/concert color magenta`, `/concert mode sweep 100`, `/concert aim 90 45`,
`/concert fire 30` (бабах конфетти и огня вокруг), `/concert burst off` + `/concert on` (непрерывный поток).
Командные блоки с такими командами позволяют сделать световое шоу по таймеру.

## Структура
- `src/main/java/com/concertmod` — код (блоки, tile-сущности, рендер луча, команда)
- `src/main/resources/assets/concertmod` — модели, блокстейты, текстуры (сгенерированы), локализация ru/en

## Самый простой способ получить .jar (без установки Java и Forge)
1. Зарегистрируйся на github.com (бесплатно) и создай новый репозиторий.
2. Загрузи в него содержимое этой папки целиком (Add file → Upload files), включая скрытую папку `.github`.
3. Открой вкладку **Actions**, дождись зелёной галочки (5–15 минут).
4. Открой завершившийся запуск и внизу в разделе Artifacts скачай `concertmod-jar` — внутри будет `.jar` для папки `mods`.
